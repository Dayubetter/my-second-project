分页查询-PageHelper
- 使用步骤

1. 引入pagehelper依赖
2. 定义mapper接口的查询方法(无需考虑分页)
3. 在Service方法中实现分页查询

一 pom.xml
```xml
<!-- 引入pagehelper依赖 -->
<dependency>
<groupId>com.github.pagehelper</groupId>
<artifactId>pagehelper-spring-boot-starter</artifactId>
<version>1.4.7</version>
</dependency>
```
二 mapper接口
```java
// 查询员工数据
@Select("select e.* from emp e ...")
public List<Emp> list();
```
三 Service方法
```java
public PageResult<Emp> page(Integer pageNum, Integer pageSize) {
    // 1.设置分页参数
    PageHelper.startPage(pageNum, pageSize);
    // 2，调用Mapper接口方法
    List<Emp> epmList = empMapper.list();
    // 3. 解析并封装结果
    return new PageResult<Emp>(...);
}
```
