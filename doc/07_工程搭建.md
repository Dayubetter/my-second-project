Nginx反向代理
- 前后端联调测试

```nginx.conf
server { 
    listen 90;
    # 省略
    location ^~ /api/ {
        rewrite ^/api/(.*)$ /$1 break;
        proxy_pass http://127.0.0.1:8080;
    }
}
```

1. location:用于定义匹配路径匹配的规则
2. ^~ /api/:表示精确匹配，即只匹配以/api/开头的请求路径
3. rewrite:该指令用于重写匹配到的路径
4. proxy_pass:该指令用于代理转发，它将匹配到的请求转发给位于后端的指令服务器
